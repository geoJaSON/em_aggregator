# Network access

The server needs outbound **HTTPS (port 443)** to each feed it polls. Nothing listens for inbound
connections from the feeds. Viewers' browsers additionally load map tiles from `*.basemaps.cartocdn.com`,
`tile.openstreetmap.org` and `server.arcgisonline.com`.

* `emagg hosts` prints the hosts your current `config.yaml` needs (use it for a firewall or proxy allowlist).
* `emagg hosts --catalog` prints every host any catalog feed can contact (the list below).

## Claude Code on the web

If you develop in a Claude Code cloud session, its environment's network policy decides what the session can
reach. Open the environment menu in the session's title bar, choose **Edit**, and under **Network access**
either choose a broader level or add these hosts to the allowed domains. Access levels are described at
https://code.claude.com/docs/en/claude-code-on-the-web.
